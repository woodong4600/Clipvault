<VS Code에서 Git으로 GitHub에 파일 올리는 법>
1. GitHub에 repository 만들기
2. 올릴 파일만 있는 폴더 만들기
3. 파일을 VS Code로 열기
4. VS Code 터미널 열기
5. git init
6. git branch -M main
7 .git remote add origin https://github.com/woodong4600/(repository이름).git
   (이미 origin이 있다면 : git remote set-url origin https://github.com/woodong4600/(repository이름).git)
8. git add (파일 이름)
9. git status [오류 뜨는지 확인]
10. git commit -m "(커밋 내용)"
11. [이미 올린 전적이 있다면 : git pull origin main --rebase]
12. git push -u origin main

git init

git remote add origin https://github.com/woodong4600/Clipvault.git
